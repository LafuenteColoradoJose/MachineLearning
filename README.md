# Repositorio de Machine Learning e Inteligencia Artificial 🤖📈

Bienvenido a mi repositorio personal de aprendizaje y proyectos prácticos sobre **Machine Learning**, **Ciencia de Datos** e **Inteligencia Artificial**.

Este espacio recopila mis ejercicios, scripts, análisis exploratorios (EDA) y modelos predictivos creados durante mi formación y especialización en el área.

## 📂 Estructura del Repositorio

El repositorio está organizado en varios bloques temáticos y proyectos independientes:

### 1. `Proyecto_AEMET/`
Un laboratorio completo de datos reales sobre el clima de España. Incluye:
- Conexión a la API de la AEMET para extraer datos históricos de temperatura y precipitación.
- Scripts de limpieza y transformación de datos (Data Wrangling) usando **Pandas**.
- Scripts de visualización de evidencias de cambio climático usando **Matplotlib** y **Seaborn**.
*(Consulta el README interior de esa carpeta para más detalles).*

### 2. `CusoEspecializacion-IABD/`
Carpeta destinada a almacenar apuntes, diagramas de módulos y material de mi Curso de Especialización en Inteligencia Artificial y Big Data.

### 3. `EjerciciosMachineLearning-Ligdi_Gonzalez/`
Colección de ejercicios prácticos basados en tutoriales, abarcando conceptos básicos de limpieza de datos, preprocesamiento y entrenamiento de modelos sencillos.

### 4. `Machine Learning Aplicado usando Python IFCD093PO/`
Prácticas estructuradas de un curso aplicado, separadas en categorías clásicas:
- **Aprendizaje Supervisado**: Regresiones (Lineal, Múltiple, Logística), K-Nearest Neighbors (KNN), Random Forest y Support Vector Machines (SVM).
- **Aprendizaje No Supervisado**: K-Means Clustering y Principal Component Analysis (PCA).

## 🛠️ Tecnologías y Librerías Utilizadas
- **Lenguaje**: Python 3
- **Gestión de Entornos**: Entorno virtual local (`.venv`)
- **Manipulación de Datos**: Pandas, NumPy
- **Visualización**: Matplotlib, Seaborn
- **Machine Learning**: Scikit-Learn
